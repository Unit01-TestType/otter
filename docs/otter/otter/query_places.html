overpass_places.py

Query OpenStreetMap populated places through the Overpass API.

The public interface is the single function:

query_places()

The function returns a pandas.DataFrame containing point locations and selected OSM metadata.

Optionally, administrative metadata can be attached to each place. The administrative divisions are returned as descriptive attributes only; administrative boundary geometry is NEVER downloaded.

Supported place types:

city
town
village
hamlet

Default:

city + town

Supported output formats, inferred from filename:

.csv
.xlsx
.xls
.geojson
.json
.shp

The canonical in-memory return value is always a pandas.DataFrame.

For GeoJSON and Shapefile output, point geometry is constructed from longitude/latitude at the final output stage.

Dependencies:

requests
pandas

Optional dependencies for geospatial output:

geopandas
shapely
fiona

Optional dependency for Excel output:

openpyxl

BASIC USAGE

Import the function:

from overpass_places import query_places

1. Query cities and towns

The default behavior returns cities and towns within the bounding box.

places = query_places(
    bbox=(
        37.0,     # south
        -123.0,   # west
        42.0,     # north
        -119.0,   # east
    )
)

The returned object is a pandas.DataFrame.

2. Query only cities

cities = query_places(
    bbox=(
        37.0,
        -123.0,
        42.0,
        -119.0,
    ),
    place_types=("city",),
)

3. Query villages and hamlets

NAME LANGUAGES

OpenStreetMap normally stores the local/default place name in:

name

Additional languages are commonly stored as:

name:en
name:es
name:fr
name:de
name:zh
name:ja

and so forth.

The function can use these language-specific tags without making additional Overpass requests.

5. Use the local/default name

This is the default behavior.

places = query_places(
    bbox=(
        37.0,
        -123.0,
        42.0,
        -119.0,
    )
)

The main name column is taken from:

name

6. Request one language

For example, request English names:

places = query_places(
    bbox=(
        37.0,
        -123.0,
        42.0,
        -119.0,
    ),
    name_languages="en",
)

The main "name" column will contain the English OSM name (name:en) when available.

If English is not available for a particular place, the local "name" value is used for that row.

If name:en is completely absent from the entire result set, a warning is issued and the local/default names are used.

7. Request multiple languages

Multiple languages can be requested:

places = query_places(
    bbox=(
        37.0,
        -123.0,
        42.0,
        -119.0,
    ),
    name_languages=(
        "en",
        "es",
        "fr",
    ),
)

The returned DataFrame will contain:

name
name_en
name_es
name_fr

The language-specific columns contain the corresponding OSM language-specific names when available.

The main "name" column uses the first requested language available for each individual place.

For example, with:

name_languages=("en", "fr", "de")

a place with only:

name:fr

will use its French name as "name".

A place with:

name:de

but no English or French name will use its German name.

If none of the requested language names exist for a place, the local "name" value is used.

8. Missing languages

If a requested language is completely absent from the returned data, the function issues a warning.

For example:

places = query_places(
    bbox=(37.0, -123.0, 42.0, -119.0),
    name_languages=("en", "xx"),
)

If no name:xx tags exist, a warning similar to the following is generated:

Requested language 'xx' is not available in the returned
OSM data. Available language tags: en, es, fr, de

The available languages are determined from the actual OSM tags returned by Overpass.

The unavailable language column is still created, but its values will be missing.

9. Language fallback

Language selection is performed independently for every place.

For:

name_languages=("en", "es", "fr")

the selection priority is:

1. name:en
2. name:es
3. name:fr
4. name

Thus the function does not discard a place merely because its preferred language is unavailable.

CUSTOM OVERPASS QUERIES

16. Use a custom Overpass query

A custom query can be supplied through the query parameter.

The query must contain:

{bbox}

For example:

custom_query = """
[out:json][timeout:60];

node
  ["place"="city"]
  ({bbox});

out body;
"""

cities = query_places(
    bbox=(
        37.0,
        -123.0,
        42.0,
        -119.0,
    ),
    query=custom_query,
)

17. Custom query with language selection

Language handling occurs after the Overpass response is received, so custom queries normally do not need to do anything special for language support.

For example:

custom_query = """
[out:json][timeout:60];

node
  ["place"~"^(city|town)$"]
  ({bbox});

out body;
"""

places = query_places(
    bbox=(
        37.0,
        -123.0,
        42.0,
        -119.0,
    ),
    query=custom_query,
    name_languages=("en", "fr"),
)

The OSM node's name, name:en, name:fr, etc. tags are returned by "out body" and processed by the Python code.

DESIGN NOTES

This module intentionally treats populated places as POINT FEATURES.

Administrative information is used only as descriptive metadata.

The module does NOT:

* download administrative boundary polygons
* download multipolygon geometry
* construct administrative polygons
* perform point-in-polygon operations
* spatially join places to administrative polygons

This keeps the returned dataset lightweight and appropriate for applications whose primary data product is a table of populated-place locations.

 737@dataclass(frozen=True)
 738class BBox:
 739    """
 740    Geographic bounding box.
 741
 742    Coordinate order:
 743
 744        south, west, north, east
 745    """
 746
 747    south: float
 748    west: float
 749    north: float
 750    east: float
 751
 752    def __post_init__(self):
 753
 754        if not -90.0 <= self.south <= 90.0:
 755            raise ValueError(
 756                "south must be between -90 and 90."
 757            )
 758
 759        if not -90.0 <= self.north <= 90.0:
 760            raise ValueError(
 761                "north must be between -90 and 90."
 762            )
 763
 764        if not -180.0 <= self.west <= 180.0:
 765            raise ValueError(
 766                "west must be between -180 and 180."
 767            )
 768
 769        if not -180.0 <= self.east <= 180.0:
 770            raise ValueError(
 771                "east must be between -180 and 180."
 772            )
 773
 774        if self.south >= self.north:
 775            raise ValueError(
 776                "south must be less than north."
 777            )
 778
 779        if self.west >= self.east:
 780            raise ValueError(
 781                "west must be less than east."
 782            )
 783
 784    @classmethod
 785    def from_tuple(
 786        cls,
 787        bbox: Iterable[float],
 788    ) -> "BBox":
 789
 790        values = tuple(bbox)
 791
 792        if len(values) != 4:
 793            raise ValueError(
 794                "bbox must contain exactly four values in the form "
 795                "(south, west, north, east)."
 796            )
 797
 798        return cls(
 799            south=float(values[0]),
 800            west=float(values[1]),
 801            north=float(values[2]),
 802            east=float(values[3]),
 803        )
 804
 805    def as_overpass(self) -> str:
 806
 807        return (
 808            f"{self.south:.7f},"
 809            f"{self.west:.7f},"
 810            f"{self.north:.7f},"
 811            f"{self.east:.7f}"
 812        )
 813
 814    def split(
 815        self,
 816    ) -> tuple["BBox", "BBox", "BBox", "BBox"]:
 817
 818        mid_lat = (
 819            self.south + self.north
 820        ) / 2.0
 821
 822        mid_lon = (
 823            self.west + self.east
 824        ) / 2.0
 825
 826        return (
 827            BBox(
 828                self.south,
 829                self.west,
 830                mid_lat,
 831                mid_lon,
 832            ),
 833            BBox(
 834                self.south,
 835                mid_lon,
 836                mid_lat,
 837                self.east,
 838            ),
 839            BBox(
 840                mid_lat,
 841                self.west,
 842                self.north,
 843                mid_lon,
 844            ),
 845            BBox(
 846                mid_lat,
 847                mid_lon,
 848                self.north,
 849                self.east,
 850            ),
 851        )

 890    """

 894    def __init__(
 895        self,
 896        path: Optional[str | Path],
 897    ):
 898
 899        self.enabled = path is not None
 900
 901        if not self.enabled:
 902
 903            self.connection = None
 904            return
 905
 906        self.path = (
 907            Path(path)
 908            .expanduser()
 909        )
 910
 911        self.path.parent.mkdir(
 912            parents=True,
 913            exist_ok=True,
 914        )
 915
 916        self.connection = sqlite3.connect(
 917            str(self.path),
 918            timeout=30,
 919        )
 920
 921        self.connection.execute(
 922            """
 923            CREATE TABLE IF NOT EXISTS overpass_cache (
 924                cache_key TEXT PRIMARY KEY,
 925                created_at REAL NOT NULL,
 926                response TEXT NOT NULL
 927            )
 928            """
 929        )
 930
 931        self.connection.commit()

 933    def get(
 934        self,
 935        key: str,
 936    ) -> Optional[dict]:
 937
 938        if not self.enabled:
 939            return None
 940
 941        row = self.connection.execute(
 942            """
 943            SELECT response
 944            FROM overpass_cache
 945            WHERE cache_key = ?
 946            """,
 947            (key,),
 948        ).fetchone()
 949
 950        if row is None:
 951            return None
 952
 953        try:
 954
 955            return json.loads(
 956                row[0]
 957            )
 958
 959        except json.JSONDecodeError:
 960
 961            logger.warning(
 962                "Ignoring invalid JSON in Overpass cache."
 963            )
 964
 965            return None
 966
 967    def put(
 968        self,
 969        key: str,
 970        response: dict,
 971    ) -> None:
 972
 973        if not self.enabled:
 974            return
 975
 976        self.connection.execute(
 977            """
 978            INSERT OR REPLACE INTO overpass_cache
 979            (
 980                cache_key,
 981                created_at,
 982                response
 983            )
 984            VALUES (?, ?, ?)
 985            """,
 986            (
 987                key,
 988                time.time(),
 989                json.dumps(response),
 990            ),
 991        )
 992
 993        self.connection.commit()
 994
 995    def close(self) -> None:
 996
 997        if self.connection is not None:
 998            self.connection.close()
